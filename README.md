# Rajab Family animation

Open `index.html` in a modern browser. All CSS, JavaScript, and the family photo are embedded in this single file. It works offline and can be shared on its own; no assets folder or server is required.

The 18-second animation forms a heart and RAJAB FAMILY from particles, then reveals the family photograph. Replay, Pause/Play, Fullscreen, and Change family photo are available. A replacement photo lasts until reload.
